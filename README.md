## Selected projects

**[Credit Risk Analysis](https://github.com/Arti-D/credit-risk-project)**  
Predicting serious delinquency on 150,000 observations. Compared Logistic
Regression, Random Forest and XGBoost, evaluated calibration, and explored
the trade-off between approval rates and missed high-risk borrowers.

**[Product Analytics: Payment Flow A/B Test](https://github.com/Arti-D/product-analytics-test-task)**  
Analyzed a payment funnel, checked data quality, and estimated the conversion
difference using user-level cluster bootstrap to account for repeated
payment attempts. Includes a notebook and a report with recommendations
and limitations.

**Market Data Pipeline · In progress**  
Building an asynchronous pipeline for trades and order-book data:
snapshots, incremental updates, order-book reconstruction, integrity checks,
storage and frontend visualization.
